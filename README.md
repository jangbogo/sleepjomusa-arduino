# Sleep Jomusa — Arduino

> 블루투스로 받은 단축 명령에 따라 RGB LED 밝기를 조절하고 온습도를 회신하는 아두이노 펌웨어. 2018 AppJam 출품작 **Sleep Jomusa** 의 하드웨어 파트.

수면 환경을 조명과 온습도로 다루는 AppJam 프로젝트에서, **아두이노 쪽 펌웨어**를 담당한 저장소입니다.
모바일 앱이 블루투스 시리얼로 보낸 문자를 받아 조명 색·밝기를 바꾸고, 요청이 오면 DHT11 센서 값을 읽어 되돌려 줍니다.

라이브러리 의존을 최소화하고(내장 `SoftwareSerial` + `DHT` 하나), 명령 프로토콜도
**"숫자 여러 개 + 명령 문자 1개"** 형태의 단순 텍스트로 설계해 앱 쪽 구현 부담을 줄였습니다.

---

## ✨ 주요 기능

- **RGB LED 개별 밝기 제어** — R / G / B 각 채널을 0~255 범위에서 따로 조절 (`analogWrite` PWM)
- **가변 길이 밝기 입력** — `5q`, `50q`, `255q` 처럼 1·2·3자리 숫자를 모두 인식
- **온습도 측정 회신** — `t` 명령 수신 시 DHT11 의 습도·온도를 읽어 블루투스로 전송
- **디버그 출력** — 수신 바이트와 센서 값을 USB 시리얼 모니터에도 동시에 출력
- **버퍼 리셋** — `\n` 또는 `x` 수신 시 입력 버퍼 위치를 초기화

## 🏗 아키텍처

```
[모바일 앱]
     │  Bluetooth Serial (9600 bps)
     ▼
[블루투스 모듈] ── RX:D6 / TX:D7 ──▶ [Arduino]
                                        │
                                        ├─ 수신 바이트를 buffer[256] 에 누적
                                        │
                                        ├─ 명령 문자 도달 시 해석
                                        │    q → red   밝기
                                        │    w → blue  밝기
                                        │    e → green 밝기
                                        │    t → DHT11 측정 후 회신 ──▶ [모바일 앱]
                                        │    \n, x → 버퍼 초기화
                                        │
                                        └─ lightOn() → analogWrite(R/G/B)
```

### 명령 프로토콜

숫자를 먼저 보내고 마지막에 **명령 문자 한 글자**를 붙이는 방식입니다.
버퍼에 쌓인 자릿수로 값을 해석하므로, 값을 보낼 때마다 `x` 또는 개행으로 버퍼를 비워 줘야 합니다.

| 명령 | 형식 | 동작 | 예시 |
|---|---|---|---|
| `q` | `<0~255>q` | Red 밝기 설정 | `200q` → 빨강 200 |
| `w` | `<0~255>w` | Blue 밝기 설정 | `80w` → 파랑 80 |
| `e` | `<0~255>e` | Green 밝기 설정 | `5e` → 초록 5 |
| `t` | `t` | 온습도 측정 후 회신 | 응답: `Humidity: 55 %\tTemperature: 27 C` |
| `x` / `\n` | — | 입력 버퍼 위치 초기화 | 다음 명령 전 호출 |

값이 `0` 이면 해당 채널의 상태 플래그(`redState` 등)가 꺼짐으로 기록됩니다.

### 핀 배치

| 역할 | 핀 |
|---|---|
| DHT11 데이터 | D2 |
| 블루투스 RX / TX | D6 / D7 |
| Blue LED (PWM) | D9 |
| Green LED (PWM) | D10 |
| Red LED (PWM) | D11 |

> LED 핀은 `analogWrite` 를 쓰므로 **PWM 지원 핀**이어야 합니다 (Uno 기준 D9·D10·D11 모두 해당).

## 🚀 시작하기

### 준비물
- Arduino Uno 등 AVR 보드
- DHT11 온습도 센서
- 블루투스 시리얼 모듈 (HC-06 계열)
- RGB LED + 저항

### 라이브러리 설치
Arduino IDE → **스케치 > 라이브러리 포함하기 > 라이브러리 관리**에서 `DHT sensor library` 를 설치합니다.
(`SoftwareSerial` 은 IDE 에 기본 포함되어 있습니다.)

### 업로드
1. 위 **핀 배치**대로 회로를 연결합니다.
2. `sketch_aug18b.ino` 를 Arduino IDE 로 엽니다.
3. 보드와 포트를 선택하고 업로드합니다.

### 동작 확인
- 시리얼 모니터를 **9600 baud** 로 열면 수신 바이트와 센서 값을 확인할 수 있습니다.
- 블루투스로 연결한 뒤 `200q` → `x` → `t` 순서로 보내면 빨간 LED가 켜지고 온습도가 회신됩니다.

## 📌 알려진 한계

2018년 AppJam 기간에 작성된 코드로, 현재 기준으로 보면 다음 부분이 남아 있습니다.

- `setup()` 에서 `dht.begin()` 을 호출하지 않습니다. 센서가 불안정하면 이 줄을 추가해야 합니다.
- `setState()` / `setLight()` 헬퍼는 정의만 되어 있고 실제로 호출되지 않습니다.
- 수신 버퍼(`buffer[256]`) 의 오버플로 검사가 없어, 버퍼를 비우지 않고 계속 보내면 범위를 넘습니다.
- 명령 문자를 버퍼에 넣은 뒤 자릿수로 값을 해석하는 구조라, 명령마다 `x`/개행으로 버퍼를 비우는 규약을 지켜야 합니다.
